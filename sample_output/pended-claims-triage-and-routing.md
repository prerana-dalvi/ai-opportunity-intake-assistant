# AI Opportunity Intake Brief: Pended Claims Triage and Routing

**Business area:** Claims  
**Workflow domain:** Claims Processing  
**AI patterns:** Decision Support, Workflow Automation, Knowledge Retrieval (RAG)  
**Sponsor:** Director, Claims Operations  
**Priority score:** 90.0/100 — **Quick Win**

## Use case summary
Claims teams face this challenge: Pended claims sit in a single queue; examiners pick work manually, so high-dollar and timely-filing-risk claims age past SLA. This opportunity applies Decision Support, Workflow Automation, Knowledge Retrieval (RAG) within Claims Processing to prioritize and route pended claims by edit type, dollar value and SLA risk so examiners work the right claims first.

## Business value hypothesis
We believe an AI assistant that can score and rank cases so reviewers see the highest-impact items first, with the reasons shown will save about 1,000 staff hours per month for Claims, measured by reviewer agreement rate with ai ranking; time-to-decision and cycle time.

Estimated capacity released: **~1,000 hrs/month (~6.25 FTE)** — planning estimate, validate against baseline.

## Initial solution concept
An AI assistant will score and rank cases so reviewers see the highest-impact items first, with the reasons shown. Staff remain in control: the assistant suggests, a person confirms. Every suggestion is logged with its source so supervisors can audit it. A pilot with one team validates accuracy and adoption before scaling.

## Draft requirements
- Secure, read-only integration with Claims adjudication system, Edit/audit codes, Examiner skills matrix
- Human review and override for every AI suggestion, with reason codes
- Audit log of inputs, outputs, model version and reviewer action
- Role-based access aligned to HIPAA minimum-necessary
- Baseline metrics captured before pilot (volume, handle time, error rate)
- Evaluation dataset and acceptance thresholds agreed with business owner
- Deployment only on BAA-covered, approved AI platform

## Success metrics
- Reviewer agreement rate with AI ranking; time-to-decision
- Touchless / straight-through processing rate
- Answer accuracy on golden question set; average handle time
- Staff hours saved per month (target ~1,000)
