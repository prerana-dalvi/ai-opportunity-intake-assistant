## Use case summary
Provider Enrollment teams face this challenge: Enrollment specialists manually re-key data from uploaded licenses, W-9 forms and ownership disclosures into the MMIS provider enrollment record, creating a backlog during revalidation cycles. This opportunity applies Document Intelligence, Workflow Automation, Knowledge Retrieval (RAG) within Provider Enrollment & Data to extract and pre-populate fields so specialists only verify, reducing backlog and turnaround time.

## Business value hypothesis
We believe an AI assistant that can extract key fields from incoming documents, validate them against system data, and pre-populate the work item will save about 412 staff hours per month for Provider Enrollment, measured by field-extraction accuracy (target >= 95% on validation set) and cycle time.

Estimated capacity released: **~412 hrs/month (~2.58 FTE)** — planning estimate, validate against baseline.

## Initial solution concept
An AI assistant will extract key fields from incoming documents, validate them against system data, and pre-populate the work item. Staff remain in control: the assistant suggests, a person confirms. Every suggestion is logged with its source so supervisors can audit it. A pilot with one team validates accuracy and adoption before scaling.

- Baseline metrics captured before pilot (volume, handle time, error rate)
- Evaluation dataset and acceptance thresholds agreed with business owner
